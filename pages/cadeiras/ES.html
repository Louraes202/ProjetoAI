Engenharia de Software

2º Ano | 2º Semestre | 6 ECTS

Resumo

Esta cadeira aborda metodologias e práticas para desenvolver software de qualidade. Aprenderás UML, padrões de design, testes e metodologias ágeis como Scrum.

Objetivos de Aprendizagem

  • Aplicar metodologias de desenvolvimento
  • Modelar sistemas com UML
  • Usar padrões de design
  • Implementar testes de software
  • Trabalhar em equipa com metodologias ágeis

Conteúdos Programáticos

1. Metodologias▼
  • Waterfall
  • Scrum
  • Kanban
  • DevOps
2. UML▼
  • Diagramas de classes
  • Diagramas de sequência
  • Diagramas de casos de uso
  • Diagramas de estado
3. Design Patterns▼
  • Singleton, Factory
  • Observer, Strategy
  • MVC
4. Testing▼
  • Unit testing
  • Integration testing
  • TDD
