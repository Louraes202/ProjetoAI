Estruturas de Dados

1º Ano | 2º Semestre | 8 ECTS

Resumo

Esta cadeira é fundamental para qualquer programador. Aprenderás como organizar e manipular dados de forma eficiente usando estruturas como listas, pilhas, filas, árvores e grafos, além de algoritmos de ordenação e pesquisa.

Objetivos de Aprendizagem

  • Implementar e utilizar listas ligadas
  • Compreender pilhas e filas
  • Trabalhar com árvores binárias
  • Implementar algoritmos de ordenação
  • Analisar complexidade de algoritmos

Conteúdos Programáticos

1. Listas Ligadas▼
  • Listas simplesmente ligadas
  • Listas duplamente ligadas
  • Listas circulares
  • Operações (inserção, remoção, pesquisa)
2. Pilhas e Filas▼
  • Pilhas (LIFO)
  • Filas (FIFO)
  • Filas de prioridade
  • Aplicações práticas
3. Árvores▼
  • Árvores binárias
  • Árvores binárias de pesquisa
  • Travessias (in-order, pre-order, post-order)
  • Árvores AVL
4. Algoritmos de Ordenação▼
  • Bubble Sort, Selection Sort, Insertion Sort
  • Merge Sort, Quick Sort
  • Análise de complexidade (Big O)
