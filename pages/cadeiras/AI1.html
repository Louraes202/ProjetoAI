Aplicações para a Internet I

2º Ano | 1º Semestre | 6.5 ECTS

Resumo

Esta cadeira introduz o desenvolvimento web client-side. Aprenderás HTML5, CSS3, JavaScript e os fundamentos de React. É a base para criar websites dinâmicos e interativos. Este projeto é o resultado prático dessa aprendizagem!

Objetivos de Aprendizagem

  • Estruturar páginas web com HTML5 semântico
  • Estilizar interfaces com CSS3 moderno
  • Programar interatividade com JavaScript
  • Criar componentes com React
  • Implementar websites responsivos

Conteúdos Programáticos

1. HTML5▼
  • Estrutura semântica
  • Formulários e validação
  • Elementos multimédia
  • Acessibilidade
2. CSS3▼
  • Seletores e especificidade
  • Box model e layout
  • Flexbox e Grid
  • Animações e transições
  • Responsive design (media queries)
3. JavaScript▼
  • Sintaxe e tipos de dados
  • DOM manipulation
  • Eventos e handlers
  • Fetch API e JSON
  • localStorage
4. React (Básico)▼
  • Componentes funcionais
  • JSX
  • Props e State
  • Hooks básicos (useState, useEffect)
