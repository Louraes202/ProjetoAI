Perguntas Frequentes

Tens dúvidas sobre a plataforma ou sobre o curso de Engenharia Informática? Encontra aqui as respostas às perguntas mais comuns.

Sobre a Plataforma

O que é a plataforma Resumos LEI? ▼

A Resumos LEI é uma plataforma comunitária criada por estudantes de Engenharia Informática da ESTGV (Escola Superior de Tecnologia e Gestão de Viseu). O objetivo é centralizar resumos, material de estudo e recursos úteis para ajudar os alunos do curso a terem sucesso académico.

Quem pode usar esta plataforma? ▼

A plataforma é aberta a todos! Embora tenha sido criada principalmente para estudantes de LEI da ESTGV, qualquer pessoa interessada em consultar o material pode fazê-lo gratuitamente.

Como posso contribuir com os meus resumos? ▼

Podes contribuir de duas formas:

  • Através do formulário na página de Contactos
  • Abrindo um Pull Request no nosso repositório GitHub
Os resumos estão atualizados? ▼

Fazemos o nosso melhor para manter o material atualizado, mas como é uma plataforma comunitária, alguns conteúdos podem estar desatualizados. Recomendamos sempre verificar com os materiais oficiais das cadeiras e contactar-nos se encontrares informação incorreta.

Sobre o Curso de LEI

Quantas cadeiras tem o curso? ▼

O curso de Licenciatura em Engenharia Informática (LEI) da ESTGV tem um total de aproximadamente 29 unidades curriculares distribuídas por 3 anos (6 semestres). Cada ano tem tipicamente 10 cadeiras, divididas entre os dois semestres.

Quais são as cadeiras mais difíceis? ▼

A dificuldade é subjetiva e varia de pessoa para pessoa. No entanto, algumas cadeiras frequentemente mencionadas como desafiantes incluem:

  • Análise Matemática - requer bases sólidas de matemática
  • Programação Orientada a Objetos - salto conceptual importante
  • Sistemas Operativos - conceitos de baixo nível
  • Bases de Dados - modelação e SQL podem ser complexos
É preciso saber programar antes de entrar? ▼

Não! O curso começa do zero com cadeiras como Algoritmos e Programação. No entanto, ter alguma familiaridade com lógica e computadores pode ajudar. Se quiseres preparar-te, podes explorar recursos gratuitos online sobre lógica de programação.

Qual linguagem de programação se usa mais? ▼

Ao longo do curso, vais trabalhar com várias linguagens:

  • C - primeiras cadeiras de programação
  • Java - POO e algumas cadeiras de 2º/3º ano
  • JavaScript/HTML/CSS - Aplicações para a Internet
  • SQL - Bases de Dados
  • Python - algumas cadeiras avançadas

Dicas de Estudo

Como devo organizar o meu tempo de estudo? ▼

Recomendamos a técnica de estudo distribuído: estudar um pouco todos os dias é mais eficaz do que maratonas antes dos exames. Usa ferramentas como calendários ou apps de produtividade (Notion, Todoist) para planeares o teu semestre.

Os resumos substituem ir às aulas? ▼

Não! Os resumos são um complemento, não um substituto. Ir às aulas permite-te tirar dúvidas em tempo real, perceber o que o professor considera importante, e muitas vezes os professores dão dicas sobre os exames.

Devo fazer projetos fora das aulas? ▼

Sim, sem dúvida! Projetos pessoais são a melhor forma de consolidar conhecimento e de teres algo para mostrar no teu CV. Começa pequeno - uma calculadora, um to-do list, um site pessoal - e vai aumentando a complexidade.

Onde posso encontrar mais recursos de estudo? ▼

Para além desta plataforma, recomendamos:

  • YouTube - canais como Curso em Vídeo, freeCodeCamp
  • Stack Overflow - para dúvidas de programação
  • MDN Web Docs - documentação web excelente
  • GeeksforGeeks - algoritmos e estruturas de dados
  • LeetCode/HackerRank - prática de programação

Não encontraste a tua resposta?
